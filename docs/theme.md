# テーマ

公開ページ（ポートフォリオ・Lab・認証画面）は **藤** テーマ、実包管理帳簿は **ブラッシュ・ノワール** テーマで表示します。
定義はどちらも `src/lib/theme/colors.css` にあります。

## 藤（サイト既定）

ほぼ無彩色の地と本文に、アバターの髪色から取った藤色を 1 色だけ差します。ライト / ダークを切り替えられます。

| 役割 | ライト | ダーク |
| --- | --- | --- |
| 地（`background`） | 青みをわずかに含む白 `#FDFCFE` | 墨色 `#141317` |
| 本文（`foreground`） | 墨 `#1D1C23` | 明るいグレー `#E8E7EB` |
| 補助テキスト（`muted-foreground`） | `#696770` | `#9F9DA5` |
| アクセント（`primary`） | 藤 `#724EA0` | 淡い藤 `#C4A8E9` |

- 藤色はリンクのホバー、フォーカスリング、選択範囲、主要ボタンに限って使う
- カードや影、グラデーションで区切らず、余白と左揃えの列で情報を整理する
- 補助テキストは地・ホバー面のどちらに対しても WCAG AA（4.5:1）以上のコントラストを保つ

### タイポグラフィ

- 和欧とも **LINE Seed JP**（400 / 700 / 800）の 1 書体。定義: `src/lib/theme/portfolio-fonts.ts`
- 和文は `word-break: auto-phrase` で文節単位に改行する（`(site-chrome)/layout.tsx`）

### レイアウト

- ヘッダー・本文・フッターは同じ幅（`max-w-3xl`）の 1 カラムで、左端を揃える
- セクションは `LabeledSection`（デスクトップでは見出しを左列に置く）、一覧の行は `EntryRow` を使う

## ブラッシュ・ノワール（実包管理帳簿）

帳簿は PWA のテーマカラー（ワイン `#6B3560`）と揃えた独自の見た目を保つため、ライト固定のブラッシュ・ノワールを使います。

- 帳簿レイアウトのラッパーに `ammo-ledger-theme` クラスを付け、`:root:has(.ammo-ledger-theme)` でトークンを上書きする
- Dialog などは body 直下へポータルされるため、ラッパー要素ではなく `:root` 側で切り替えている

## 切り替え

- `next-themes` で `html` に `.dark` クラスを付与（公開ページのみ）
- 初期値は OS 設定（`system`）。ヘッダーのトグル（モバイルはメニュー内）でライト / ダークを手動切替
- 実装: `src/lib/theme/theme-provider.tsx`, `src/lib/theme/theme-toggle.tsx`

## トークン

shadcn / Tailwind と同じ変数名（`--background`, `--primary` など）を使います。
